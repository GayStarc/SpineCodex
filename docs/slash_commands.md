# Slash commands

For an overview of Codex CLI slash commands, see [this documentation](https://developers.openai.com/codex/cli/slash-commands).

When SpineJIT, SpineTrim, or SpineSpawn is enabled for the current thread,
`/feedback` uses SpineCodex's content-redacted rollout report and optional
screenshot flow. See [Spine feedback and privacy](./spine-feedback.md).
